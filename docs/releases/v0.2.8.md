# Medchron v0.2.8 — Windows Installer

## Download for Windows

**[Download the Medchron Windows installer](https://github.com/TomSellecksMustache/Medchron/releases/download/v0.2.8/Medchron-Setup-Windows-x64.exe)**

This stable release incorporates the RC2 People Workspace updates: a 30-day chronology calendar, compact subsequent-upload bar, PDF previews and per-field confirmations, local OCR, and automatic identity matching. Phone-only identity links require confirmation; provider numbers are excluded from patient matching. Documents that cannot be matched reliably stay Unassigned.

The installer includes bundled local OCR tools and 30 fictional medical-record PDFs representing five synthetic identities.

## Privacy and limitations

Medchron is a local-first demonstration prototype. Authentication and encryption at rest are not implemented or enforced. Do not use real patient/client records.
