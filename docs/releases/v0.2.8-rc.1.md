# Medchron v0.2.8-rc.1 — Automatic Intake Release Candidate

**Pre-release for demonstration and testing.** The latest stable Windows installer remains the default download until a stable replacement passes testing.

## Windows installer

**[Download the Windows installer](https://github.com/TomSellecksMustache/Medchron/releases/download/v0.2.8-rc.1/Medchron-Setup-Windows-x64.exe)**

Installs Medchron under `C:\Program Files\Medchron`, creates a branded desktop shortcut, and starts a **local-only** browser interface at `http://127.0.0.1:56753`.

## What's new

- A single PDF file picker and drag-and-drop intake target; import begins on selection or drop.
- Offline PDF extraction and OCR using locally bundled Tesseract and Poppler.
- Automatic sidebar grouping of 30 synthetic records into **five fictional people**, each with six documents.
- Your original Medchron logo prominently displayed in the interface.
- Individual profiles, local chronology review, document sidebar and in-page PDF preview.
- Encryption plumbing retained but **not enabled**; data remains unencrypted at rest.

## Privacy and limitations

This is a local-first prototype, not production-ready legal or clinical software. No real client identifiers, medical records, or documents should be sent to GitHub. No login system or active encryption at rest exists yet. OCR-generated identities and candidate events require verification against originals. Files with uncertain or conflicting identities remain Unassigned.

The installer and portable ZIP include 30 **entirely synthetic** PDFs for safe demonstration. This release candidate is **not** the stable/latest download.
