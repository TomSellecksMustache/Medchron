# Medchron v0.2.8-rc.2 — Calendar & document verification RC

**Windows installer (prerelease)**

[Download Medchron v0.2.8-rc.2 Windows installer](https://github.com/TomSellecksMustache/Medchron/releases/download/v0.2.8-rc.2/Medchron-Setup-Windows-x64.exe)

The latest **stable** Windows download continues to point to v0.2.7. This candidate is provided for demonstration testing.

## People Workspace improvements

- Original Medchron logo in a clean, transparent header lockup; no duplicate hero image
- 30-day calendar centered on today's date, with highlighted dates detected in uploaded PDFs
- After first intake, the drop zone becomes a horizontal PDF-upload bar
- Profile fields below the calendar and visible only when a person is selected
- Unconfirmed PDFs display ⚠ in the right documents rail
- Open a PDF to review OCR-suggested **name, date, phone, and patient/health-card ID**; select or deselect individual verification checkmarks, then confirm
- Drag a document from **Unassigned** in the right rail onto the correct person in the **left** rail; it remains unconfirmed until explicitly verified
- Automatic local OCR, five-person grouping, and the 30 synthetic demonstration PDFs retained
- Calendar synchronization with Microsoft 365, Google, and Apple is **not enabled** (future integration only)

## Privacy and review

This remains a prototype: no user authentication or encryption at rest. All OCR and storage are local by default; no calendar or cloud AI providers receive records. **Use synthetic records only**. Confirming document identity is independent of accepting chronology events. Check original PDFs before relying on either.
