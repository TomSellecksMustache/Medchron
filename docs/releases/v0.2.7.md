# Medchron v0.2.7 — Offline OCR and reviewed batch intake

Medchron can now extract scanned PDFs locally and import documents for multiple people after you review and confirm every assignment.

## Windows download

**[Download the Windows x64 installer](https://github.com/TomSellecksMustache/Medchron/releases/download/v0.2.7/Medchron-Setup-Windows-x64.exe)**

The installer includes the local server, desktop launcher, Tesseract, English language data, Poppler, and 30 vetted synthetic demonstration PDFs. The workspace opens at `http://127.0.0.1:56753/`. A portable Windows ZIP and SHA-256 checksums are also attached.

## Changes

- **Offline OCR:** searchable text is used where available; image-only pages fall back to local OCR. OCR quotations remain unverified until checked against the original PDF.
- **Reviewed batch intake:** analyze up to 30 PDFs, review proposed names, choose a new person or explicitly select an existing saved person, and confirm import. Analysis creates no cases, and saved cases never merge by name alone.
- **People and documents:** confirmed records appear in the People sidebar and the selected person's document library. Original PDFs, source page references, and chronology exports remain available.
- **Storage boundary:** case metadata and uploaded PDFs share a codec interface for future encryption. Plaintext is still the only implemented mode; `encrypted-v1` refuses startup without a plaintext fallback.
- **Upload limits:** multipart uploads honor the documented 25 MB per-PDF limit and 100 MB request limit, including PDFs larger than 2 MB.
- **Release checks:** the Windows workflow validates packaged OCR against four fictional scanned PDFs and captures the actual browser workspace before publishing.

## Validation and limitations

Ubuntu validation covered all 14 Rust tests, formatting, Clippy with warnings denied, and a local build. Real Tesseract OCR detected the correct names in all four scanned fixtures, created two reviewed person records, kept OCR entries unverified, and passed existing-person import, single upload, source-PDF retrieval, CSV export, and temporary-file cleanup checks.

The Windows release job separately checks the tagged source, builds both executables and the installer, verifies sample integrity and packaged OCR, and captures the screenshots attached above. A manual Windows installation smoke test is still recommended.

Medchron remains a demonstration prototype. There is no authentication, encryption at rest, or complete audit trail. OCR and identity suggestions require human review. Use synthetic records only; do not publish client records or case data. The optional CUDA/PaddleOCR adapter remains experimental.
